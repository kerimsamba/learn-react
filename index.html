What is a "hook", in one sentence?

A hook is a special function (its name starts with use…) that lets a component remember things and react to changes between renders.

🧠
Think of a component as a function that runs again and again every time something changes. On its own it forgets everything each run. Hooks give it a memory and a way to run side-effects at the right moments.
